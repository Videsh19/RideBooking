# GoRide Server Services Layer

This directory will contain the business logic services in Phase 2 once the approved UML class diagram and SRS specifications are integrated:

- `authService.js` — User authentication, password hashing, and session tokens
- `riderService.js` — Rider profile management and ride history
- `driverService.js` — Driver onboarding, availability status, vehicle telemetry
- `bookingService.js` — Ride requests, dispatch matching algorithms, status state-machine
- `fareService.js` — Distance, duration, base fare, and surge calculation rules
- `adminService.js` — Fleet overview, user moderation, platform telemetry

*Phase 1 Status:* Intentionally left unpopulated to respect Phase 1 scope restrictions.
